## 方法说明

- 全部数据来自**公开信息与一手体验**，逐项标注来源与口径
- 累计值还原单季流水、跨表拼接、来源分级（A/B/C/D），每份报告均设「分析局限」专章
- 报告中的推断均给出**可证伪的验证方法**，而非直接结论
- 《问剑长生》与《杖剑传说》同属一家公司、同年上线、底层架构接近，构成变量可控的对照组
